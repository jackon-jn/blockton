Privacy Policy

This policy covers Blockton Uploader, a private tool the Blockton channel owner uses to publish videos to their own TikTok, Instagram and YouTube accounts.

Who uses the tool

Only the channel owner. The tool is not offered to the public, and no other person signs in to it.

What data it accesses

  • Sign-in tokens that the channel owner grants through each platform's official login (Google OAuth, TikTok Login Kit, Instagram Login).
  • Basic profile information of the owner's own accounts (account ID and name), used only to confirm which account a video is posted to.
  • The videos, titles and captions the owner publishes.

The tool does not collect, read or store data about viewers, followers or any other user.

How the data is used and stored

Tokens are stored only on the owner's own computer, in a file readable by the owner alone, and are used only to upload and publish the owner's videos. Nothing is sold, shared with third parties, used for advertising, or used to train AI models.

YouTube and Google

Blockton Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Blockton Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

Data deletion

To delete all data the tool holds, revoke its access in each platform's settings (Google: link above; TikTok: Settings → Security → Apps and services; Instagram: Settings → Website permissions → Apps and websites) and the owner deletes the local token files. A deletion request can also be sent through the contact link below; it is completed within 30 days.
